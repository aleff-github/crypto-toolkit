# Privacy Policy

Crypto Toolkit does not collect, transmitr, sell, or share user data. It contains no telemetry, analytics, remote API calls, cloud services, advertising SDKs, or hidden background workers.

All operations are performed locally. Selected text, keys, secrets, IVs, JWTs, and generated values are processed in memory only for the requested operation. Crypto Toolkit does not persist secrets, keys, IVs, passwords, HMAC secrets, or AES material.
