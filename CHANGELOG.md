# Changelog

## 1.0.0 - 2026-05-07

Initial Marketplace-ready release.

### Added

- Native `Crypto` editor context menu.
- Encode/decode actions: Base64, Base64URL, Hex, URL, HTML.
- Hash actions: MD5, SHA1, SHA256, SHA512.
- HMAC actions: HMAC-SHA256, HMAC-SHA384, HMAC-SHA512.
- JWT Decode.
- AES-CBC and AES-GCM helpers.
- JSON, Unix timestamp, UUID, random token, sort lines and unique lines utilities.
- Smart Detect side panel.
- Offline/local-only design with no telemetry or network calls.

### Removed before public release

- Experimental Workbench/WebView panel.
- Experimental advanced JWT signing/verification menu items.
- Experimental Recipes and Web Security menus.
